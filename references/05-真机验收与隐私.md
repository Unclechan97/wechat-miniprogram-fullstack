# 05 · 真机验收与隐私授权

> **铁律**：开发者工具通过 ≠ 真机能用。隐私接口、音频、域名校验在真机的行为都与工具不同。发版前必须有一轮完整的真机验收。

## 5.1 体验版全流程

1. 开发者工具 **上传**（版本号如 1.0.0 + 备注）。上传有两条路：
   - GUI：工具右上角「上传」按钮
   - **CLI（AI/CI 可代劳）**：`<工具安装目录>\cli.bat upload --project <miniprogram目录> -v 1.0.0 -d "备注"`——需先在工具「设置 → 安全设置」打开服务端口（参数以官方文档为准）
2. mp 后台 → **管理 → 版本管理** → 开发版本 → **设为体验版**
3. 后台 → 成员管理 → 把测试用的微信号加为**体验成员**
4. 手机扫码进入体验版

**体验版可否长期用？** 可以，没有时间限制：
- 只有"体验成员"能进入（扫码/链接），普通用户搜不到
- 体验成员有数量上限（个人主体约 15 人，以控制台为准）——给家人小范围长期用足够；做公开产品必须正式发布
- 你上传新版本并重设体验版后，"体验版"自动更新为新版本

## 5.2 ★ 隐私保护指引（真机接口全挂的头号原因）

**规则**：凡是用了隐私接口（麦克风/相册/摄像头/位置等），必须在后台配置《用户隐私保护指引》并**收录对应信息类型**，否则：

- 开发者工具：**完全不校验，一切正常**
- 真机：接口调用直接被拒（无弹窗或直接 fail）——表现就是"功能在工具里好好的，手机上没反应"

**配置位置**：mp 后台 → 设置 → 服务内容声明 → 用户隐私保护指引 → 编辑

**用途文案模板**（可直接抄）：

| 信息类型 | 用途文案 |
|---|---|
| 麦克风 | 用于语音输入记账：录制你说的话并转换为文字，识别消费金额和分类后记账。 |
| 照片或视频信息（相册） | 用于拍照或从相册选择小票、支付截图，识别其中的金额和分类用于记账。 |
| 摄像头 | 用于拍摄小票或支付截图，识别记账信息。 |
| 6.2 变更告知方式 | 弹窗 |

**易漏点**：
- `wx.chooseMedia` 的 `sourceType: ['camera']` 用了**摄像头**——不要只配"相册"，摄像头要单独"增加信息类型"
- 隐私指引本身也要过审（几小时~1 天），和改名/类目并行提交
- 配置生效后**杀掉小程序重新进入**才生效

**★ 没有隐私接口的产品 ≠ 不用管**：不需要配置指引，但**提审时必须在提审页勾选/声明「未采集用户隐私」**，否则提交会被拦截（见 06 §6.3）。

## 5.3 真机 vs 开发者工具差异清单（实测汇总）

| 差异点 | 工具 | 真机 | 对策 |
|---|---|---|---|
| 录音格式 | 模拟器不支持 wav | 都支持 | 统一录 mp3，服务端归一化 16k wav |
| 录音文件格式 | 与移动端不同（工具提示原文） | 标准 | 工具录音只能工具里调试，不要用工具音频判断音质问题 |
| iOS 静音开关 | 不存在 | **静音键打开时音频无声** | `audio.obeyMuteSwitch = false`（适老/通知类产品必设） |
| 音频解码缓存 | 同路径文件覆盖后可能播旧内容 | — | 每次写**唯一文件名**（`tts-<时间戳>.mp3`），播完删除上一个 |
| RecorderManager | 偶发 start() 无响应（无 onStart 也无 onError） | 较少见 | 1.5s 看门狗：未进录音态则 stop+重试一次，仍不行给明确文案 |
| 隐私接口 | 不校验 | **必须配隐私指引** | 见 5.2 |
| 域名校验 | 可勾"不校验合法域名"绕过（**只对工具内生效**） | 体验版/正式版强制校验；http 明文需在**手机端打开调试**（仅开发/体验版可开，正式版无解） | 数据走 callContainer；直连通道真机需自有备案域名，否则静默回退 |
| 局域网预览 | — | 手机连不上电脑 | 同一 WiFi + **Windows 防火墙放行服务端口**（不放行=报网络错误） |
| 权限弹窗 | 无 | 首次调用弹"允许使用麦克风？" | 用户拒了要有兜底文案 + 手动输入通道 |

## 5.4 音频类功能验收清单

- [ ] 麦克风权限弹窗正常弹出（拒绝后走手动输入兜底）
- [ ] 录音→上传→识别全链路（录多个不同内容）
- [ ] 播报出声（**分别在静音模式开/关下测**）
- [ ] 连续多次录音/播报无串音、无卡死
- [ ] 点击快、松开即停；<1 秒的误触有友好提示
- [ ] 弱网（开飞行模式再关/切 4G）下的重试与提示

## 5.5 提审前真机验收（终验）

在"体验版 + 关调试模式"（= 最接近正式版的环境）下完整走一遍所有功能：

- [ ] 每个页面的核心流程
- [ ] 每个隐私接口的授权流程（首次弹窗→允许/拒绝两种分支）
- [ ] 网络异常提示文案（老人能看懂，不出现英文错误码）
- [ ] 全新用户（未授权过）的首次体验
- [ ] 无隐私接口的产品：裁剪隐私相关项，但提审页的「未采集用户隐私」声明仍要处理（见 5.2）
